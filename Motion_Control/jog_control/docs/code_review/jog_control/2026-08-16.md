### 1. 목적

DSS 차량 수동 조작(jog) Qt5 GUI. `/dss/control` (dss_ros2_bridge/DssControl) 을 20 Hz 상시 발행하고,
버튼·키를 누르는 동안만 값이 실리며 떼면 0 (dead-man). 수신·UDP 전달은 dss_ros2_bridge 의
`DSSControlNode` 소관.
