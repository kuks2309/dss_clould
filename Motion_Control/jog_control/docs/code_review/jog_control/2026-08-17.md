### 1. 목적

DSS 차량 수동 조작(jog) Qt5 GUI. **조그 Enable 토글이 ON 인 동안만** `/dss/control/jog`
(dss_ros2_bridge/DssControl) 을 20 Hz 상시 발행하고, enable 상태를 `/dss/jog_enabled`
(std_msgs/Bool, latched) 로 알린다. OFF 면 발행 전면 중단 — 제어권은 `/dss/control`(자율 노드).
버튼·키를 누르는 동안만 값이 실리며 떼면 0 (dead-man). 소스 선택·UDP 전달은 dss_ros2_bridge 의
`DSSControlNode`(mux) 소관.
